# Assessment Filler - ABLLS-R

Static ABLLS-R assessment tool for browser and phone use.

## Local Run

```bash
python3 -m http.server 3000
```

Open `http://127.0.0.1:3000/`.

## Deploy To Vercel

1. Push this repo to GitHub.
2. Import the GitHub repo into Vercel.
3. Use the default project root.
4. If Vercel asks for a framework preset, choose `Other`.
5. Deploy.

The site is a static app, so no environment variables are required.
