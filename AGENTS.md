## Learned User Preferences
- Prefers phone-first UI that minimizes scrolling and keeps key actions easy to reach in the thumb zone.
- Prefers focused/mobile views to keep the current question and answers visible without scrolling, with compact pinned navigation when possible.
- Prefers mobile section/alphabet navigation as a compact grid rather than a list.
- Prefers selected answer choices to be visually obvious with stronger color contrast.

## Learned Workspace Facts
- Workspace is a static ABLLS-R assessment web app adapted from a single-file HTML project.
- Workspace is intended to be deployed on Vercel and used from a phone.
- Assessment progress is currently stored client-side in browser localStorage, with no backend persistence path.
- The app is expected to support additional assessment types beyond ABLLS-R.
- The app supports import/export workflows, including mobile-friendly share export when available.
